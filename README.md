### I · The 4 a.m. train
<sub><i>Every day, his father worked so his son could study.</i></sub>

My father had a degree in mathematics and caught the 4 a.m. train so I could go to the best school in the city. When the class laughed at the boy who wanted to be M.F. Husain, a teacher drew a little star on my cheek and said:

> *“Always believe in your dreams.”*

I kept drawing, kept filling registers with maths, took a drop year solving Irodov for the joy of it, and got into **BITS Pilani**.

### III · Fireflies
<sub><i>But then, the wind changed.</i></sub>

In my final year my father passed away, at the peak of COVID. I set research aside, took the internship whose stipend could carry the family, and learned what he had already shown me: *strength isn't avoiding struggle; it's carrying it with grace.*

<details>
<summary><b>🪁 About the site</b></summary>

[shashankmishra.bio](https://shashankmishra.bio) is a single scrolling picture book built on Pixar's story spine — *Once upon a time → Every day → One day → But one night → Because of that ×2 → Until finally → And every day since.*

| Piece | What it is |
| --- | --- |
| [`/site`](./site) | Vite + vanilla JS, inline SVG + canvas, zero runtime dependencies |
| One wind field | `wind(t)` drives the kite, tail, string sag, grass, sea, smoke, clouds, fireflies and letters; scrolling gusts it |
| [`/design`](./design) | Prototype, Blender-rendered textures (`blender/scene.py`), character plates and the original score |
| Hosting | GitHub Pages via `.github/workflows/deploy-site.yml`; DNS on Hostinger |

Respects `prefers-reduced-motion`; music plays only when you tap the record.

```bash
cd site && npm install && npm run dev
```

See [`site/README.md`](./site/README.md) for build & deployment details.
